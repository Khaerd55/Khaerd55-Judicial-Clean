# Judicial Clean 5.11.14

ارفع محتويات هذا المجلد إلى جذر المستودع، مع مجلد `.github` كاملاً.
من تبويب Actions اختر Build Windows Setup ثم Run workflow.
بعد نجاح البناء نزّل Judicial-Clean-Setup-5.11.14-x64 من Artifacts وفك الضغط للحصول على ملف exe.
يبني المسار نسخة Windows x64 بدون توقيع رقمي. لا يتضمن قاعدة بيانات المستخدم.

تم توحيد رقم إصدار package-lock واسم ملف التثبيت وإضافة استثناء قواعد البيانات من الحزمة.
لم يتم تغيير منطق البرنامج. فحص صياغة JavaScript نجح؛ التشغيل والطباعة وبناء Windows لم تُختبر هنا.
