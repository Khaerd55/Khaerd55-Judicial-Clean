V5.10.4 - Installer Ready

هذه النسخة مبنية على V5.10.3 وتضيف إعداد electron-builder فقط لإنشاء Setup لويندوز.
لم يتم تغيير منطق الحملات أو المذكرات أو المخاطبات أو قاعدة البيانات.

على جهاز Windows داخل مجلد المشروع:
1) npm.cmd install
2) npm.cmd run dist

بعد اكتمال البناء ستجد ملف التثبيت داخل مجلد dist باسم قريب من:
Judicial-Setup-5.10.4.exe

مهم: ملف Setup لا يحتوي قاعدة بيانات جهازك الحالي تلقائياً. بعد تثبيت البرنامج على الجهاز الآخر استخدم زر استعادة نسخة احتياطية واختر مجلد النسخة الاحتياطية الذي أنشأته من الجهاز الأصلي.
